# 家計マスター — Sisankanri

月別の収支・予算を管理する、日本語の家計簿アプリです。HTML 1ファイルで動作します。

## GitHub Pagesで使う

リポジトリの Settings → Pages → Build and deployment で、Source を Deploy from a branch、Branch を main、フォルダーを / (root) にして Save します。
公開完了後、Pages設定に表示されたURLをSafariなどで開いてください。

## 後からデータを読み込む

初回画面の「バックアップCSVを読み込む」、または「設定」のバックアップ読み込みから、以前に書き出した kakei-master-backup-*.csv を選択します。
支出・収入・目標・追加ジャンルを読み込みます。同じバックアップを再読込しても、既存の同一明細は件数を照合してスキップします。目標はCSVの値で更新されます。
通常の支出明細CSVは「新しい支出明細CSVを読み込む」を使います。

## 保存について

家計データは操作したブラウザのlocalStorageに保存します。GitHubへの送信や端末間の自動同期はありません。別端末には設定からバックアップCSVを書き出して移してください。ブラウザのデータ削除で保存内容が消えるため、定期的なバックアップをおすすめします。
公開リポジトリにはアプリのコードだけを置き、個人のCSV・収入・支出は含めていません。CSVとテキストは誤追加防止のため.gitignoreで除外します。

## ローカル利用

index.htmlをJavaScript対応ブラウザで開きます。ファイルのプレビュー画面では操作できない場合があります。
